Secured Embed — RSA + JWT Authentication

Production-grade security using asymmetric RSA-2048 key pairs. Every chat request is authenticated with a short-lived JWT signed by your backend — the widget never talks to wxO without a valid token.

✓ Production-grade 🔑 RSA-2048 + JWT RS256 → Requires JWT signing server

How it works — architecture

The secured embed uses asymmetric RSA cryptography. You generate a key pair: the private key stays on your server, the public key is uploaded to the wxO tenant. For each page load, your backend signs a JWT with the private key. The widget passes this JWT to wxO, which verifies it using the public key. No private key ever leaves your server.

Your Server
JWT Signing Service
  • Holds RSA private key
  • Signs JWT on request
  • Never exposed to browser
  • scripts/jwt_server.py
  • Runs on port 3001
Browser
Your Web Page
  • Fetches JWT from /api/token
  • Passes JWT via identityToken
  • Never sees private key
  • Refreshes token on expiry
  • wxoLoader.init() with callback
IBM Cloud
wxO Platform
  • Holds your public key
  • Verifies JWT signature
  • Rejects unsigned requests
  • Issues session ticket
  • Streams chat responses
Key insight: The RSA public key is uploaded once to the wxO tenant UI. After that, every token issued by your backend is automatically trusted by wxO — no API calls to IBM Cloud are needed at signing time.

Setup — step by step

  1. Generate an RSA-2048 key pair

    Run this from the project root. It creates keys/wxo_embed_private.pem and keys/wxo_embed_public.pem. The keys/ folder is already in .gitignore.

    bash 
    bash scripts/generate_rsa_keys.sh

    The script prints the public key at the end — keep this terminal open for step 3.

  2. Add the private key path to .env

    .env
    EMBED_PRIVATE_KEY_FILE=keys/wxo_embed_private.pem
JWT_SERVER_PORT=3001
JWT_EXPIRY_SECONDS=3600
ALLOWED_ORIGINS=http://localhost:8080

  3. Upload the public key to the wxO tenant

    Open eu-de.watson-orchestrate.cloud.ibm.com → Administration → Settings → Embed Security tab.

    Toggle Security: ON. Paste the entire contents of keys/wxo_embed_public.pem into the Public key field (including the -----BEGIN PUBLIC KEY----- header). Click Save.

    Note: You can retrieve the public key at any time with: cat keys/wxo_embed_public.pem

  4. Start the JWT signing server

    bash
    # Activate the venv first
source venv/bin/activate

# Start the JWT server in one terminal
python scripts/jwt_server.py

# Start the web server in another terminal
python3 -m http.server 8080 --directory web

    The JWT server listens on http://localhost:3001.

  5. Open this page and verify

    Navigate to http://localhost:8080/demo-secured.html. Use the token inspector below to verify the server is running and tokens are being issued correctly.

Secured embed code

The key difference from the unsecured version is the identityToken callback inside chatOptions. The widget calls this function each time it needs a fresh JWT.

JavaScript — webchat-secured.js 
// ── Secured wxO embed configuration ────────────────────────────────────────
// Difference from unsecured: chatOptions.identityToken callback.
// The widget calls this function whenever it needs a fresh JWT.
// Your JWT server signs it — the browser never sees the private key.

window.wxOConfiguration = {
  orchestrationID: "e65910fa61ce9072d64902d03f3d4774_75c2cabb-2b02-4d65-8127-a9cc65d1ee46",
  hostURL:         "https://eu-de.watson-orchestrate.cloud.ibm.com",
  rootElementID:   "wxo-chat-root",
  showLauncher:    true,
  crn:             "crn:v1:bluemix:public:watsonx-orchestrate:eu-de:a/...",
  deploymentPlatform: "ibmcloud",
  chatOptions: {
    agentId:            "5c3c69c8-be40-44c8-9681-3e7f21c64072",
    agentEnvironmentId: "dba7f186-fe9b-4d42-9735-ba2601645aac",

    // ── identityToken: called by the widget on every auth refresh ────────
    identityToken: {
      // Called once on init, then whenever the current token nears expiry.
      getToken: async function() {
        // 1. Call your JWT signing backend (simple GET — no body, no Content-Type)
        const res = await fetch("http://localhost:3001/api/token");
        if (!res.ok) throw new Error(`Token server error: ${res.status}`);

        // 2. Extract the JWT string and return it
        const data = await res.json();
        return data.token;  // must be a raw JWT string
      }
    }
  }
};

// ── Pass user context (optional) ─────────────────────────────────────────
// For authenticated pages, send user ID/name so it appears in chat history.
async function getTokenForUser(userId, userName) {
  const res = await fetch("http://localhost:3001/api/token", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ userId, name: userName })
  });
  const { token } = await res.json();
  return token;
}

// ── Load the wxO chat widget ────────────────────────────────────────────────
setTimeout(function() {
  const script = document.createElement("script");
  script.src  = window.wxOConfiguration.hostURL + "/wxochat/wxoLoader.js?embed=true";
  script.async = true;
  script.addEventListener("load", () => wxoLoader.init());
  document.head.appendChild(script);
}, 0);
Python — scripts/jwt_server.py (key sections) 
# ── Token factory ─────────────────────────────────────────────────────────
import jwt as pyjwt, time, uuid

def create_jwt(user_id=None, user_name=None, extra_claims=None):
    """Sign a JWT with the RSA private key loaded from EMBED_PRIVATE_KEY_FILE."""
    now = int(time.time())
    payload = {
        "iss": "ibm_bob_assistant_demo",    # issuer
        "sub": user_id or f"anonymous-{uuid.uuid4().hex[:8]}",  # subject
        "aud": "watsonx-orchestrate",          # audience
        "iat": now,                            # issued at
        "exp": now + EXPIRY_SECONDS,           # expiry (max 7100s)
        "jti": str(uuid.uuid4()),              # unique token ID
    }
    if user_name:  payload["name"] = user_name
    return pyjwt.encode(payload, PRIVATE_KEY_PEM, algorithm="RS256")

# ── HTTP endpoint: POST /api/token ─────────────────────────────────────────
# Receives optional { userId, name } body, returns { token, expires_in }
def do_POST(self):
    body = json.loads(self.rfile.read(int(self.headers["Content-Length"])))
    token = create_jwt(
        user_id=body.get("userId"),
        user_name=body.get("name"),
    )
    self._json(200, {
        "token":      token,
        "expires_in": EXPIRY_SECONDS,
        "token_type": "Bearer",
    })

Unsecured vs Secured — side by side

🔓 Unsecured

  • No backend needed
  • Zero configuration code
  • Works on any static host
  • No user identity
  • Anyone can use your agent
  • No audit trail
  • Disable security in wxO UI first

🔒 Secured (JWT)

  • RSA-2048 asymmetric signing
  • Short-lived tokens (≤ 7100s)
  • User identity propagated to wxO
  • Audit trail in wxO logs
  • Compatible with SSO / OAuth
  • Required for enterprise agents
  • Requires JWT signing server
  • More initial setup
