Unsecured Embed — Anonymous Access

No JWT, no RSA keys, no backend server required. The wxO chat widget loads and authenticates automatically once you disable embed security on your wxO tenant.

✓ Simplest setup → 1 prerequisite: disable security on wxO tenant ⚠ Anonymous — no user identity

What is unsecured embed?

By default IBM watsonx Orchestrate has embed security enabled, which requires every chat request to carry a signed JWT. When you disable that setting, the widget performs anonymous authentication automatically — no keys, no backend, no token signing required.

⚠ When to use this mode: public demos, internal prototypes, chatbots with no access to sensitive data or credentials. Never use unsecured mode when the agent has access to enterprise systems, PII, or OAuth connections.

Prerequisites — one-time tenant configuration

You only need to do this once per wxO instance. After this the embed script below will work immediately.

  1. Log in to your wxO instance

    Open https://eu-de.watson-orchestrate.cloud.ibm.com and sign in with your IBM Cloud credentials.

  2. Open Administration → Settings

    Click your profile icon in the top-right corner, then select Administration → Settings from the navigation menu.

  3. Click the "Embed Security" tab

    You will see a Security toggle and a Public key field.

  4. Toggle Security to OFF

    Click the Security switch to turn it OFF. A warning dialog will appear — confirm the action.

    Warning from IBM: Disabling security allows any website to embed and use your agent without authentication. Only do this for demo/anonymous use cases.

  5. Save and verify

    Click Save. The widget on this page will now load successfully — try clicking the chat bubble below.

Embed code

This is the complete client-side code to embed the chat widget. There is no backend requirement — everything runs in the browser.

HTML / JavaScript 
<!-- 1. Add a container div where the widget will render -->
<div id="wxo-chat-root"></div>

<!-- 2. Paste this script near </body> -->
<script>
  window.wxOConfiguration = {
    orchestrationID: "e65910fa61ce9072d64902d03f3d4774_75c2cabb-2b02-4d65-8127-a9cc65d1ee46",
    hostURL:         "https://eu-de.watson-orchestrate.cloud.ibm.com",
    rootElementID:   "wxo-chat-root",
    showLauncher:    true,
    crn:             "crn:v1:bluemix:public:watsonx-orchestrate:eu-de:a/...",
    deploymentPlatform: "ibmcloud",
    chatOptions: {
      agentId:            "5c3c69c8-be40-44c8-9681-3e7f21c64072",
      agentEnvironmentId: "dba7f186-fe9b-4d42-9735-ba2601645aac"
    }
  };
  setTimeout(function() {
    const s = document.createElement("script");
    s.src = window.wxOConfiguration.hostURL + "/wxochat/wxoLoader.js?embed=true";
    s.addEventListener("load", () => wxoLoader.init());
    document.head.appendChild(s);
  }, 0);
</script>
JavaScript — webchat-config.js 
// ── Configuration ──────────────────────────────────────────────────────────
window.wxOConfiguration = {
  orchestrationID: "e65910fa61ce9072d64902d03f3d4774_75c2cabb-2b02-4d65-8127-a9cc65d1ee46",
  hostURL:         "https://eu-de.watson-orchestrate.cloud.ibm.com",
  rootElementID:   "wxo-chat-root",
  showLauncher:    true,
  crn:             "crn:v1:bluemix:public:watsonx-orchestrate:eu-de:a/...",
  deploymentPlatform: "ibmcloud",
  chatOptions: {
    agentId:            "5c3c69c8-be40-44c8-9681-3e7f21c64072",
    agentEnvironmentId: "dba7f186-fe9b-4d42-9735-ba2601645aac"
  }
  // NOTE: No identityToken callback — that is only used in the secured mode.
};

// ── Load the wxO chat widget ────────────────────────────────────────────────
setTimeout(function() {
  const script = document.createElement("script");
  script.src  = window.wxOConfiguration.hostURL + "/wxochat/wxoLoader.js?embed=true";
  script.async = true;

  script.addEventListener("load", function() {
    if (typeof wxoLoader !== "undefined" && typeof wxoLoader.init === "function") {
      wxoLoader.init();
      console.info("[wxO] Chat widget initialised (unsecured/anonymous mode)");
    } else {
      console.error("[wxO] wxoLoader not available — check hostURL and network.");
      showChatError("Failed to load chat loader. Check console.");
    }
  });

  script.addEventListener("error", function(e) {
    console.error("[wxO] wxoLoader.js failed to load:", e);
    showChatError("Network error loading chat. Check CSP and internet access.");
  });

  document.head.appendChild(script);
}, 0);

// ── Error display helper ────────────────────────────────────────────────────
function showChatError(msg) {
  const el = document.getElementById(window.wxOConfiguration.rootElementID);
  if (!el) return;
  el.innerHTML = `<p style="color:#da1e28;padding:16px">⚠ ${msg}</p>`;
}

When to use — and when not to

  • Public product demos with no sensitive data
  • Internal prototypes where all users are trusted
  • Rapid testing during development
  • Agents with only read-only public knowledge bases
  • Agents connected to enterprise systems (Workday, ServiceNow, etc.)
  • Any agent that can read or write PII or financial data
  • Production deployments with a real user base
  • Rate limiting is not enforced — anyone can spam your agent
