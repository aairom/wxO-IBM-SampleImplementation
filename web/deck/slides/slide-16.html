Section 04

Secured embed — key facts

RS256
JWT signing algorithm — RSA-2048 asymmetric key pair; private key never leaves the server
7100 s
Maximum token lifetime enforced by IBM watsonx Orchestrate — default is 3600 s in jwt_server.py
4
Setup steps — generate keys, upload public key, start JWT server, add identityToken callback

Source: IBM watsonx Orchestrate secured embed documentation · scripts/jwt_server.py

Two-path decision Choose unsecured (toggle OFF) for quick integration or non-sensitive public agents. Choose secured JWT for production agents with user identity, audit trails, and enterprise access control.
