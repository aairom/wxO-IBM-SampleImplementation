Section 02

Production agent architecture

Backend services

scripts/import_tools.py and scripts/import_agent.py orchestrate the full import pipeline with JSON reports written to output/. Both scripts accept --force-reimport, --dry-run, and --verbose flags for CI/CD integration.

# Exit codes
0 = success
1 = import failed
2 = YAML invalid

Runtime dependencies

requirements.txt pins orchestrate CLI, PyJWT ≥ 2.8.0, and cryptography ≥ 41.0.0. Managed via uv venv + uv pip install.

# Key env vars (never hard-coded)
ORCHESTRATE_URL
IBM_CLOUD_API_KEY
ORCHESTRATE_ENV_NAME
