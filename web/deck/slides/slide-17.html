Secured embed components

JWT architecture — component roles

generate_rsa_keys.sh

Generates RSA-2048 key pair via openssl. Outputs keys/wxo_embed_private.pem (chmod 600) and keys/wxo_embed_public.pem. Non-interactive when called from start.sh.

bash scripts/generate_rsa_keys.sh

jwt_server.py

Python HTTP server on :3001. GET / (health), GET /api/token (anon JWT), POST /api/token (user JWT). RS256 via PyJWT. CORS enabled.

python scripts/jwt_server.py

identityToken callback

Added to chatOptions in window.wxOConfiguration. Widget calls getToken() on init and before token expiry. Returns a raw RS256-signed JWT string.

identityToken: {
  getToken: async () => {
    const r = await fetch(
      "localhost:3001/api/token");
    return (await r.json()).token;
  }
}

wxO tenant config

Upload keys/wxo_embed_public.pem at Administration → Settings → Embed Security → Security: ON. wxO verifies JWTs against this key using the kid claim.
