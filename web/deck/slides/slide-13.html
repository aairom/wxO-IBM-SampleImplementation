Section 03

Unsecured embed — configuration and identifiers

Required configuration fields

window.wxOConfiguration = {
  orchestrationID: "<tenant>_<instance>",
  hostURL:         "https://eu-de.watson-orchestrate
                    .cloud.ibm.com",
  crn:             "crn:v1:bluemix:...",
  deploymentPlatform: "ibmcloud",
  chatOptions: {
    agentId:            "<agent-uuid>",
    agentEnvironmentId: "<env-uuid>"
  }
};
// Load the wxO widget dynamically
const s = document.createElement("script");
s.src = config.hostURL +
  "/wxochat/wxoLoader.js?embed=true";
s.addEventListener("load", () =>
  wxoLoader.init());
document.head.appendChild(s);

webchat-config.js is generated by get_webchat_embed.sh on every start.sh run.

Identifiers are not secrets

The orchestrationID, agentId, and agentEnvironmentId are client-visible. Per IBM documentation, anyone with these IDs can send messages and receive replies, but cannot log in, modify the agent, or retrieve logs.

What IS secret — keep in .env only

ORCHESTRATE_API_KEY
ORCHESTRATE_TOKEN  # short expiry
BOB_SEARCH_API_TOKEN
The RSA private key (secured embed only) must never appear in client-side code.
