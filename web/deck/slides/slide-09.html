Deployment command reference

CommandPurposeUse case
./scripts/start.shFull 9-step deployFirst-time setup
./scripts/start.sh --skip-kb-checkSkip KB readiness pollKB already Ready
./scripts/start.sh --force-reimportForce clean slateAfter YAML changes
./scripts/start.sh --start-jwt-serverDeploy + launch JWT serverSecured embed setup
./scripts/stop.shUndeploy allTeardown environment
./scripts/stop.sh --keep-kbKeep KB, remove agentSave re-indexing time
./scripts/cleanup.shRemove venv and cachesLocal workspace cleanup
python scripts/import_agent.py --dry-runValidate YAML onlyPre-commit checks
Idempotent by design All scripts check existing state before acting — safe to run multiple times without side effects.
