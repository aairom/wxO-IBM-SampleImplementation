Section 03

Unsecured embed — troubleshooting

Auth error banner

Authentication Error / Agent fetching failed

Cause: Embed Security toggle is ON (default state).

Fix: Administration → Settings → Embed Security → Security: OFF → Save.

This is the most common issue. It is a tenant configuration requirement, not a code bug.

Widget not loading

No chat bubble after page load

Causes: webchat-config.js is stale; CSP blocks the wxO CDN; wrong hostURL region.

Fix: Rerun get_webchat_embed.sh. Check browser console for CSP or 404 errors.

CORS errors in console

Cause: Serving from file:// instead of HTTP.

Fix: Always use python3 -m http.server 8080.

Empty agent answers

Chat loads but no relevant answers

Cause: Knowledge base not yet Ready.

Fix:

orchestrate   knowledge-bases status   -n ibm_bob_docs
# wait for Ready = True
