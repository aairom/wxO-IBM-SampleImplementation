# IBM Bob Enterprise Plan

Source: https://bob.ibm.com/docs/ide/enterprise/

## Overview

Scale IBM Bob across your organization with centralized control. IBM Bob Enterprise provides enhanced team management capabilities, shared Bobcoin allocation, and dedicated support to help your organization maximize productivity.

### Key Enterprise Features

- **Shared Bobcoin pool** — Distribute Bobcoins from a centralized budget to empower your entire team.
- **Admin dashboard** — Control spending, manage users, and track usage across your organization.
- **Enterprise support** — Get assistance from dedicated IBM Bob specialists.
- **Scale on demand** — Purchase additional Bobcoin packs as your team grows.
- **Bobalytics** — Analytics and insights into team adoption (Enterprise only).

## Centralized Management

The administration dashboard provides:

- **Shared Bobcoin pool** — Distribute Bobcoins to team members.
- **User management** — Use Seats to add, remove, and manage team member access.
- **Spending controls** — Set individual spending limits and adjust based on your team needs.
- **Usage insights** — Monitor Bobcoin consumption and optimize your resource allocation.

Your IBM Bob Enterprise plan provides access to the [Administration](https://bob.ibm.com/admin) page.

## User Roles

IBM Bob Enterprise provides two role types:

- **User** — Can access IBM Bob and use AI features within their assigned team's spending limits.
- **Admin** — Has all User permissions plus the ability to manage users, create and configure teams, and access the administration dashboard.

## Managing Users

Add users to your IBM Bob Enterprise organization, assign roles, manage seat allocation, and assign premium packages.

### Adding a User

1. Go to the [IBM Bob Administration](https://bob.ibm.com/admin) page.
2. Go to **Users & Teams** and select the **Users** tab.

### Assigning a Premium Package to a User

1. Go to the [IBM Bob Administration](https://bob.ibm.com/admin) page.
2. Go to **Users & Teams** and select the **Users** tab.
3. Select the user you want to update.
4. Under **Premium packages**, select the premium package to assign.

The user can access the premium package immediately after assignment.

### Removing a Premium Package from a User

1. Go to the [IBM Bob Administration](https://bob.ibm.com/admin) page.
2. Go to **Users & Teams** and select the **Users** tab.
3. Select the user you want to update.
4. Under **Premium packages**, deselect the premium package to remove.

**Note:** Premium package entitlements are time-bound. Each assigned package displays its active period and expiry date in the user's add-on list.

### Viewing Add-on Seat Usage

The **Add-ons** summary in the admin UI shows each premium package with its purchased seat count and how many are currently assigned.
