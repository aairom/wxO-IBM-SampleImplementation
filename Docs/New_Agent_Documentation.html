IBM Documentation Assistant Agent

Intelligent RAG assistant for live IBM Documentation crawling, indexing, and watsonx Orchestrate deployment.

1. Architecture Overview

The IBM Documentation Assistant (IBM_Doc_Assistant) provides a complete end-to-end framework for continuously indexing official IBM technical documentation into a vector store and exposing that knowledge to watsonx Orchestrate agents via native custom tools with mandatory URL attribution.

Subsystem Technology / Module Description
Documentation Scraper IBMDocScraper (Python / BeautifulSoup) Resilient HTTP crawler with exponential backoff and HTML section extraction.
Text Chunker TextChunker Section-preserving chunker with token estimation and metadata retention.
Vector Store VectorStore Cosine similarity vector index supporting local and watsonx.ai embeddings.
ADK Tools tools.py (@tool) Callable tools for semantic search and document inspection.
Deployment Automation deploy_orchestrate_agent.py One-command validator and agent/tool importer with JSON reports.

2. Ingestion & Retrieval Data Flow

[ Official IBM Docs ] ──(HTTP Scraper)──> [ Text Chunker ] ──(Embedder)──> [ Vector Store (JSON/DB) ]

3. Package Structure

src/agents/ibm_doc_agent/
├── scraper.py         # Live web crawler & parser
├── chunker.py         # Text chunking & token estimator
├── vector_store.py    # Vector similarity search engine
├── tools.py           # watsonx Orchestrate custom ADK tools
├── agent.py           # Query processing & response synthesis engine
├── openapi_spec.json  # OpenAPI 3.0 specification for tool integration
└── .env.example       # Dedicated environment variable template

4. Prerequisites & Configuration

Configure environment variables in .env using the provided template:

IBM_WATSONX_API_KEY=your-ibm-cloud-api-key
ORCHESTRATE_INSTANCE_URL=https://api.watsonx.orchestrate.ibm.com
WATSONX_PROJECT_ID=your-project-id
AGENT_NAME=IBM_Doc_Assistant
AGENT_MODEL=groq/openai/gpt-oss-120b

5. Ingestion Pipeline Execution

# Scrape and index default documentation
python3 scripts/ingest_docs.py

# Ingest specific URLs with customized chunk sizes
python3 scripts/ingest_docs.py \
  --urls "https://www.ibm.com/docs/en/watsonx/watsonx-orchestrate/current?topic=getting-started" \
  --chunk-size 600 \
  --chunk-overlap 60

6. Automated Agent Deployment

# Deploy agent and tools to watsonx Orchestrate
python3 scripts/deploy_orchestrate_agent.py

# Dry-run validation check
python3 scripts/deploy_orchestrate_agent.py --dry-run

7. Testing & Sample Prompts

Run unit tests to verify scraper, chunker, vector store, and agent execution:

pytest tests/test_ibm_doc_agent.py -v
Sample Query & Response

Query: "How do I configure custom tools in watsonx Orchestrate?"

Answer: Custom tools are registered using Python functions decorated with @tool and imported via the Orchestrate CLI or Agent Builder.

Citation: https://www.ibm.com/docs/en/watsonx/watsonx-orchestrate/current?topic=building-agents

8. Security & Compliance

  • Domain Whitelisting: Scraper restricts target URLs to verified IBM documentation hosts.
  • Credential Isolation: API keys and secrets are loaded strictly from environment variables.
  • Audit Logging: All automated runs output audit logs into output/.
