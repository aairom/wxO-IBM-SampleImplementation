IBM Bob Documentation Assistant

Comprehensive architecture, task implementation, operations manual, and reusable integration asset.

1. Executive Summary & Completed Tasks Overview

This repository provides a complete, production-ready implementation of the IBM Bob Documentation Assistant on the IBM watsonx Orchestrate (wxO) platform. The system leverages Retrieval-Augmented Generation (RAG) over indexed domain documentation, dynamic custom search tools, an RS256 token-signing backend, and modular embed clients.

Task / Module Purpose & Functionality Deliverables
Agent & KB Declarative native agent with 11 indexed technical documentation files. agents/ibm_bob_assistant.agent.yaml, knowledge-bases/ibm_bob_docs.kb.yaml
Live Search Tools Python @tool extensions for keyword & semantic document lookups. tools/live_bob_search.py
Import Automation CLI importers with schema validation and timestamped audit logs. scripts/import_tools.py, scripts/import_agent.py
Auth & Keypair RSA-2048 key generation & lightweight Python JWT signing service. scripts/generate_rsa_keys.sh, scripts/jwt_server.py

3. Prerequisites & Setup

Ensure the following software and dependencies are installed before executing operations:

  • Python: Version 3.10+ (managed with uv or standard virtualenv)
  • OpenSSL: Command line utility for RSA keypair generation
  • IBM Cloud credentials: watsonx Orchestrate instance with integrationID, region, and serviceInstanceID
# Install Python dependencies using uv (recommended)
uv venv .venv
source .venv/bin/activate
uv pip install -r requirements.txt

Task 1: Agent & Knowledge Base Architecture

Configured a native, declarative agent definition in agents/ibm_bob_assistant.agent.yaml connected to an indexed Knowledge Base in knowledge-bases/ibm_bob_docs.kb.yaml.

  • 11 Knowledge Base Documents: Granular domain files covering Bob Shell, MCP integration, security guidelines, telemetry, mode switching, skills, packages, and troubleshooting.
  • Citation Directives: System prompts mandate specific clickable markdown citations for all grounded responses.

Task 2: Dynamic Live Tool Integration

Authored high-precision custom tools using the @tool decorator in tools/live_bob_search.py:

  • search_bob_documentation(query, limit): Performs ranked keyword and phrase search against the documentation catalog.
  • get_bob_doc_section(document_id, section_title): Extracts targeted markdown headers, text blocks, and code examples.

Task 3: Automated Importers with Reporting

Developed robust automation scripts for registering tools and agent definitions to watsonx Orchestrate:

  • scripts/import_tools.py: Validates tool signatures, registers them with wxO, and outputs execution logs.
  • scripts/import_agent.py: Validates YAML definitions, links dependent tools and KBs, and saves timestamped JSON audit reports to output/.

Task 4: Cryptography & JWT Token Server

Built an end-to-end asymmetric cryptographic identity infrastructure:

  • scripts/generate_rsa_keys.sh: Generates 2048-bit PKCS#8 private key and public key PEM files into keys/.
  • scripts/jwt_server.py: Standalone Python HTTP server providing CORS-enabled /token, /public-key, and /health endpoints.

Task 5: Web Chat Client Embeds

Created production-ready web chat integration templates:

  • Unsecured Client (web/demo-unsecured.html): Public-facing embed for unauthenticated scenarios with live code tabs.
  • Secured Client (web/demo-secured.html): Enterprise-ready client with automated token acquisition via watsonxOrchestrate:requestIdentityToken, token renewal, and a live JWT debugger.

Task 6: Lifecycle Automation Scripts

Standardized operational shell scripts adhering strictly to project guidelines:

  • scripts/start.sh: Idempotent 9-step deployment pipeline.
  • scripts/stop.sh: Graceful shutdown of servers and process cleanup.
  • scripts/serve.sh: CLI switcher for hosting web apps or slide decks.
  • scripts/cleanup.sh: Removes virtual environments, caches, and temporary files.

Task 7: Test Suite & Verification

Authored comprehensive automated test suites covering tool logic, importer scripts, and embed generators: 

pytest tests/ -v
  • tests/test_live_bob_search.py: 31 unit tests validating search accuracy and section parsing.
  • tests/test_import_tools.py: 56 unit tests validating tool parsing and error resilience.
  • tests/test_import_agent.py: 54 unit tests validating schema checks and API mocks.

Task 8: Presentation Deck & Documentation Hub

Built an interactive HTML5 presentation deck (web/deck/index.html) featuring 20 modular slides designed with IBM Carbon Design tokens, keyboard navigation, and responsive typography.

Task 9: Live Documentation Scraper & Ingestion Pipeline Agent

Implemented an independent Python-based agent (IBM_Doc_Assistant) and ingestion pipeline in src/agents/ibm_doc_agent/:

  • IBMDocScraper & TextChunker: Scrapes live IBM documentation, extracts hierarchical sections, and preserves metadata.
  • VectorStore: Cosine similarity vector index supporting local and watsonx.ai embeddings.
  • deploy_orchestrate_agent.py: One-step registration script with JSON audit logs in output/.

7. Security Guidelines

Security Best Practices

1. Never expose private RSA keys to client-side code or public repositories.

2. Keep token lifetimes short (15–60 minutes) and handle refresh events automatically.

3. Always sign with RS256 to ensure asymmetric verification by watsonx Orchestrate.
